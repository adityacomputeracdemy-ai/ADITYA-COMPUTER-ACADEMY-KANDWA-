COMPUTER FUNDAMENTALS

Computer Parts — Hindi + English

Computer के मुख्य parts और उनका उपयोग।

🖥️ Monitor / मॉनिटर

English: Displays text, images, videos and software output.
हिंदी: कंप्यूटर का output स्क्रीन पर दिखाता है।

⌨️ Keyboard / कीबोर्ड

English: Used to type letters, numbers and commands.
हिंदी: अक्षर, नंबर और commands टाइप करने के लिए।

🖱️ Mouse / माउस

English: Pointing device for click, select, drag and navigation.
हिंदी: स्क्रीन पर object चुनने और control करने के लिए।

🖥️ CPU / System Unit

English: Contains processor, motherboard, RAM and storage.
हिंदी: मुख्य hardware components को रखने वाली unit।

🖨️ Printer / प्रिंटर

English: Produces hard copies of documents and images.
हिंदी: document/image की paper copy निकालता है।

💾 HDD/SSD / स्टोरेज

English: Stores files, programs and operating-system data.
हिंदी: files और software को सुरक्षित रखने के लिए।
